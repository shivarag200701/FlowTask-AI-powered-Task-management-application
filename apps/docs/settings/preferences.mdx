Flowtask gives you control over how your workspace looks and how your tasks are displayed. You can switch between dark and light themes at any time, and choose a different view layout for each individual project.

## Dark and light theme

Flowtask supports both a dark and a light interface theme. Your selected theme is saved to your browser and persists across sessions on the same device.

To switch themes, click the **theme toggle** icon in the sidebar footer. The interface updates immediately — no page reload required.

<Tip>
  Your view preference (list or board) is saved per project, so each project can have its own default layout.
</Tip>

## Default view mode

Each project in Flowtask independently remembers your preferred layout — **list view** or **board view**. When you switch views, the change applies immediately for your current session. To make the selection stick the next time you open the project, click **Set as default** in the display selector panel.

To change the view for a project, open the **Display** selector in the project header and pick the layout you want. Click **Set as default** to save it as your persistent preference for that project.

<Note>
  A **Calendar** option appears in the display selector alongside list and board. Calendar view is not yet fully implemented — selecting it may not render a complete calendar layout. Full calendar support is planned for a future release.
</Note>

## List view

List view displays all tasks in a flat, scrollable list. Each row shows:

- **Task title** — the primary label for the task
- **Description** — a short summary beneath the title
- **Tags** — color-coded labels for categorization
- **Due time** — the scheduled date and time
- **Options menu** — a context menu for quick actions such as editing, duplicating, or deleting the task

List view is well suited for reviewing all tasks at once and scanning due times quickly.

## Board view

Board view organizes your tasks as cards arranged in **Kanban-style columns**, where each column represents a section or status in your project. Board view is ideal for tracking progress through stages.

Key features of board view:

- **Drag and drop** — drag a card from one column to another to move the task between sections
- **Card details** — each card displays the task title, tags, and due time at a glance
- **Column headers** — each column shows the section name and the count of tasks within it

Switch to board view any time you want a visual overview of how work is distributed across stages.
